# THG3000 and custom OpenWRT firmware?
[Vodafone] in the UK ship an ADSL/Fibre/WiFi router referred to as the **_Vodafone Wi-fi Hub_** and this router is built by [Vantiva], formerly [Technicolor].  The standard [Vodafone] firmware is based on [OpenWRT] so the question is whether there is a way to run custom [OpenWRT] firmware on this router and add and extend functionality.

[OpenWRT]: https://www.openwrt.org
[Vodafone]: https://www.vodafone.co.uk
[Vantiva]: https://www.vantiva.com/
[Technicolor]: https://www.vantiva.com/resources/technicolor-officially-becomes-vantiva/
